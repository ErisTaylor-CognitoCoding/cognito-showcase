# Three turtles, three ways to code them

> 📺 **[Watch on YouTube →](https://youtube.com/shorts/XuLw3xPOetw?feature=share)**

Watch this. That turtle's building a computer desk — stairs, disk drive, printer, the lot. I've not touched it.

Three turtles, sat in a row. Lua, program, pastebin. Same block, same little face. This one moves one command at a time. This one runs a file and lays an orange square. And that one downloaded ninety lines off the internet and got on with it.

Same turtle, three different jobs. The only thing that changes is how the code got in.
