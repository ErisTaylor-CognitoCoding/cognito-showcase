# `f-strings` in 60 seconds

> 📺 **[Watch on YouTube →](https://youtube.com/shorts/gs2JOpP3ocA)**

---

Nobody prints a fresh name badge for every guest. They print thousands that all say HELLO my name is, with a blank left in the middle. Your code does the same thing. Put an `f` before the quotes, then curly brackets where the gap goes — whatever variable name you put between those brackets is swapped for its value the moment the line runs. No gluing text together with plus signs. No hunting for missing spaces.

```python
name = "Eris"
print(f"Hello {name}, welcome back!")
```
