# `return values` in 60 seconds

> 📺 **[Watch on YouTube →](https://youtube.com/shorts/RZCWJ9cIZW8)**

You post a form off, get on with your day, and a letter lands on the mat with the answer inside. A function does the same thing — it does the work and hands the answer straight back to the code that called it. Without the `return` line the answer vanishes the moment the job finishes, and your program is left with nothing.

```python
def double(number):
    return number * 2

answer = double(5)   # answer is now 10
```
