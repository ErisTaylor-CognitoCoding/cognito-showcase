# `parameters` & `arguments` in 60 seconds

> 📺 **[Watch on YouTube →](https://youtube.com/shorts/qba8N7oLjPM)**

---

Picture a recipe card that says: "Make tea for ___ people." You never wrote the number down — you left a gap. Later, when you make the tea, you drop a 4 into that gap. Same card, four people. Same card, forty people. You never rewrite the recipe.

Code does exactly this. The **parameter** is the blank you leave inside the function brackets. The **argument** is the real value you hand over when you call it.

```python
def make_tea(people):
    print("Boiling water for", people, "cups")

make_tea(4)   # 4 is the argument — it fills the "people" blank
```

One function, any input. Leave a blank, fill it in later.
