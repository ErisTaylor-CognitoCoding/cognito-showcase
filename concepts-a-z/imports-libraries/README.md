Nobody writes a whole book just to read one. You borrow it — you walk into a library, show your card, and take home something somebody else already spent years writing. Code works the same way, and that is genuinely why we call them libraries. The word for borrowing one is `import`. Get the name right and the whole library is yours. Get it wrong and Python says `ModuleNotFoundError` — that book isn't on the shelf.

```python
import random
print(random.choice(["red", "blue", "green"]))
```

Two lines. Borrow `random`, then ask it to pick a colour. You never wrote a word of it.
